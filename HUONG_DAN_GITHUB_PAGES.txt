HƯỚNG DẪN THÊM DASHBOARD TƯƠNG TÁC VÀO DỰ ÁN
============================================

1. GIẢI NÉN
-----------
Giải nén gói này vào THƯ MỤC GỐC của dự án:
C:\Users\Admin\Downloads\MergeSort_CUTOFF_Project\MergeSort_CUTOFF_Project

Sau khi giải nén, thư mục dự án sẽ có thêm:
- docs\index.html
- docs\.nojekyll
- scripts\setup_dashboard.ps1

Không cần xóa thư mục analysis\animated và không cần chạy lại benchmark.

2. CẬP NHẬT README.md
---------------------
Mở PowerShell tại thư mục gốc dự án và chạy:

powershell -ExecutionPolicy Bypass -File .\scripts\setup_dashboard.ps1

Script sẽ:
- Thay phần biểu đồ cũ trong README bằng liên kết tới dashboard.
- Cập nhật CPU, RAM và thông tin Windows đã xác nhận.
- Sao chép 3 CSV từ analysis\ sang docs\data\ để dashboard đọc cùng domain.
- Lưu một bản sao README trước khi sửa trong thư mục %TEMP%.

Kiểm tra README.md bằng Notepad hoặc VS Code trước khi commit.

3. KIỂM TRA CÁC FILE
--------------------
Chạy:

Test-Path .\docs\index.html
Test-Path .\analysis\summary.csv
Test-Path .\analysis\cutoff_7_10_comparison.csv
Test-Path .\analysis\best_cutoff_from_run.csv
Test-Path .\docs\data\summary.csv
Test-Path .\docs\data\cutoff_7_10_comparison.csv
Test-Path .\docs\data\best_cutoff_from_run.csv

Sau khi chạy scripts\setup_dashboard.ps1, cả bảy lệnh phải trả về True.

4. THÊM VÀ ĐẨY LÊN GITHUB
-------------------------
Chạy:

git status
git add README.md docs/ scripts/setup_dashboard.ps1
git commit -m "Add interactive CUTOFF dashboard"
git push origin main

Ba CSV trong docs\data\ sẽ được thêm cùng với dashboard. Chúng là bản sao của các tệp trong analysis\ tại thời điểm chạy script.

5. BẬT GITHUB PAGES (CẦN THAO TÁC TRÊN WEBSITE)
-----------------------------------------------
Sau khi push thành công:
- Mở repository GitHub.
- Chọn Settings.
- Chọn Pages trong menu bên trái.
- Ở Build and deployment, chọn Deploy from a branch.
- Branch: main.
- Folder: /docs.
- Nhấn Save.

GitHub Pages sẽ xuất bản trang docs/index.html tại:
https://hoangdinhdat1147.github.io/MergeSort-CUTOFF-Experiment/

6. KIỂM TRA
-----------
Mở địa chỉ dashboard sau khi GitHub Pages báo deploy thành công.
Trang sẽ đọc ba bảng CSV trong docs/data/ trên cùng domain GitHub Pages và tải thư viện Plotly.js từ CDN. Trang cần kết nối Internet để hiển thị biểu đồ. Nếu không tải được dữ liệu, trang sẽ hiển thị thông báo lỗi thay vì tự tạo số liệu.

Nếu sau này chạy lại benchmark và cập nhật các CSV trong analysis\, chạy lại scripts\setup_dashboard.ps1 để đồng bộ các bản CSV trong docs\data\ trước khi commit.

Lưu ý:
- Dashboard không chạy lại thuật toán và không thay đổi CSV.
- Nút Phát chỉ chuyển qua các kích thước mảng đã đo: 10.000, 50.000, 100.000, 250.000.
- Thanh sai số biểu thị ±1 SD, không phải khoảng tin cậy 95%.
- CUTOFF tốt nhất chỉ là giá trị thấp nhất trong 18 mức đã thử.
